# Customer Churn Analysis

## Overview
This project analyzes customer churn data from a telecom company to identify the key factors influencing customer retention and customer loss. The analysis was performed using Python for data cleaning and exploratory data analysis (EDA), and Power BI for dashboard creation and visualization.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook
- Git & GitHub

## Dataset
Telco Customer Churn Dataset

## Project Workflow
1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Analysis
5. Customer Churn Insights
6. Dashboard Creation in Power BI

## Key Insights
- Total Customers: 7043
- Customers Churned: 1869
- Churn Rate: 26.54%
- Month-to-Month contracts show the highest churn.
- Fiber Optic customers have higher churn compared to DSL customers.
- Customers using Electronic Check payment methods are more likely to churn.
- Gender has minimal impact on churn behavior.
